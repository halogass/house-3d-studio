# House data schema

This is the contract for the files the wizard (Claude) writes. Every house lives in its own folder
`projects/<name>/`:

| File | What | Who edits |
|---|---|---|
| `project.json` | settings: title, language, location, features on/off, style, spec & cost assumptions | wizard |
| `zoning.js` | the plan: plot & site items, levels, rooms, open-plan pairs, doors & windows, stairs, lift, balconies, roofs | wizard |
| `interior.js` | finishes and furniture per room, furniture outside the rooms | wizard |
| `brief.md`, `progress.md`, `style.md` | the wizard's notes (Markdown) | wizard |
| `quantities.json` | generated by `npm run quantities` (areas and volumes for the cost estimate) | generated |
| `bake/` | baked lightmaps (`npm run bake`, optional) | generated |
| `private/plans/`, `private/inspo/` | the owner's plan photos and inspiration (never committed, never uploaded) | user |
| `shots/` | screenshots (`npm run screenshots`, git-ignored) | generated |

The active house is chosen by `--project <name>` (or `PROJECT=<name>`), else the file
`.active-project`, else `sample-house`. `npm run new-project <name>` copies `projects/_template/`
and makes it active; `npm run use-project <name>` switches.

After every edit run, in this order: `npm run validate` (schema, friendly bilingual messages),
`npm run check` (walk every door both ways, every gate and stair, reach every room),
`npm run check-interior` (furniture clearances), `npm run test` (all of it plus engine tests).
The reference house is `projects/sample-house/` — copy patterns from it.

`zoning.js` and `interior.js` are ES modules: `export default { … }`. Comments are welcome (they are
the design notes). Text shown to people may be a plain string or `{ id: 'Bahasa Indonesia', en: 'English' }`.

## Coordinates and units

- Metres. Plan coordinates: **x → east, y → north**, origin `(0, 0)` = the **south-west corner of the plot**.
- A rectangle is `r: [x0, y0, x1, y1]` with `x1 > x0`, `y1 > y0`.
- **Room corners must be on a 0.5 m grid** (walls are generated on that grid). Openings, stairs,
  furniture and site items can use any value.
- Walls are generated from the room rectangles, **centred on the room edges**: exterior walls 0.30 m,
  interior walls 0.15 m. The inner wall face is therefore 0.15 m (exterior) / 0.075 m (interior)
  inside the room rectangle. Two rooms that touch share one wall unless they are an open-plan pair.
- Elevations (`elev`) are finished floor heights above the garden (grade = 0).
- Rotations (`rot`, degrees): the direction the item's **front** faces: `0` = north, `90` = east,
  `180` = south, `270` = west.
- Directions as letters: `'n' | 's' | 'e' | 'w'`.
- In the 3D engine: world X = x, world Y = elevation, world Z = −y.

## project.json

```json
{
  "name": "rumah-kami",
  "title": { "id": "Rumah Kami", "en": "Our House" },
  "language": "id",
  "location": { "city": "Bandung", "region": "jawa-barat-2026", "lat": -6.9, "lon": 107.6, "climate": "tropical highland" },
  "features": { "doors": true, "sit": true, "lift": false, "cars": true, "multiplayer": true, "spec": true,
                "cost": true, "bake": false, "site": true, "garden": true, "pv": true },
  "style": { "preset": "tropical-modern", "exteriorColor": "#efebe3", "accentColor": "#5b4a3c",
             "roof": "roofTileDark", "facade": "modern", "trim": "#2f2a26" },
  "spec": { "occupants": 4, "kwhPerPersonDay": 3.5, "litresPerPersonDay": 150, "rainfallMm": 2200,
            "runoff": 0.8, "peakSunHours": 4.2, "pvLosses": 0.8, "panelWp": 550 },
  "cost": { "region": "jawa-barat-2026", "quality": "standard" },
  "start": { "x": 5.6, "y": -3, "yaw": 0 }
}
```

| Field | Meaning |
|---|---|
| `name` | folder name: lowercase letters, digits, dashes |
| `title` | shown in the page title and the 3D view |
| `language` | default UI language `'id'` or `'en'` (visitors can switch) |
| `location.lat`, `lon` | **city level only, 1 decimal** (sun path). Never a street address. `lat` south = negative |
| `location.region` | default cost rate table (see Cost) |
| `features` | switch parts of the engine on/off (below) |
| `style.exteriorColor` | colour of the exterior render (`stucco:` factory) |
| `style.roof` | default roof material: `terracotta`, `roofTileDark`, `roofMetal`, `roofMetalLight` |
| `style.facade` | `'modern'` (dark plinth, slim sills, cylinder wall lights) or `'mediterranean'` (stone plinth, travertine sills & surrounds, cornice, lanterns) |
| `style.accentColor` | window sills (modern facade) |
| `spec.*` | household assumptions for the spec tab (energy and water) |
| `cost.region`, `cost.quality` | rate table key and `'standard' \| 'premium' \| 'luxury'`; optional `fee`, `cont`, `ppn`, `range` (%) override the table defaults |
| `start` | optional start position `{ x, y, yaw (radians), level }`; default: on the road in front of the first gate |
| `bake.areas` | optional: `[{ id, level, rooms: [...], enclosed, gain: { day, night } }]`; default one bake area per level |

**Features** (all optional, defaults shown):

| key | default | what |
|---|---|---|
| `doors` | true | doors and gates open/close (E / tap); off: leaves drawn open |
| `sit` | true | sit / lie on sofas, chairs, beds |
| `lift` | true | the home lift, when `zoning.lift` exists |
| `cars` | true | car items are drivable |
| `multiplayer` | true | "explore together" menu (Supabase via env, else same-browser tabs) |
| `spec` | true | "House spec" tab |
| `cost` | true | link to the cost estimate page |
| `bake` | false | use baked lightmaps (`npm run bake`, needs a GPU) |
| `site` | true | façade detailing, garden lights, pool ladder … |
| `garden` | true | photo vegetation (trees, beds, hedges, grass) |
| `pv` | true | solar panels on hip roofs with `pv: true` |
| `finishes`, `furniture` | true | interior finishes / furniture (off: shell only) |

## zoning.js

```js
export default {
  version: '1.0',
  site: { w, d, road, perimeter, items: [ … ] },
  levels: [ … ],
  rooms: { L1: [ … ], L2: [ … ] },
  open: { L1: [['living', 'dining']] },
  openings: { L1: [ … ], L2: [ … ] },
  fixtures: { L1: [ … ] },          // optional
  stairs: [ … ],                    // optional
  lift: { … },                      // optional
  outdoor: { L2: [ … ] },           // optional: balconies / roof terraces
  roofs: [ … ],
};
```

### site

| Field | Meaning |
|---|---|
| `w`, `d` | plot width (x) and depth (y) in metres |
| `road` | side of the plot on the road: `'s'` (default), `'n'`, `'e'`, `'w'` |
| `perimeter` | `{ front, sides, back: 'wall' \| 'fence' \| 'hedge' \| 'none', h, frontH, material }` — gaps are cut where gates are |
| `items` | site items (below) |

**Site items** — every item has `kind`, optional `id` (needed to put furniture on it, see `areas`)
and `name` (shown in the 3D view / teleport list):

| kind | geometry | params | what is built |
|---|---|---|---|
| `lawn` | `r` | | grass tufts (the whole plot is grass already) |
| `paving` | `r` | `material` (default `pavers`) | paved surface |
| `terrace` | `r` | `material` (default `paversWarm`; e.g. `teak`) | terrace floor |
| `path` | `r` | `material` (`gravel`), `lights` (default true: bollards) | path |
| `driveway` | `r` | `material` (`concrete`) | drive |
| `parking` | `r` | `bay` (2.5 m) | asphalt + bay lines |
| `carport` | `r` | `h` (2.6), `roof: 'flat' \| 'hip'`, `roofMaterial` | slab, posts (none where it touches the house), roof, light. Cars go in `areas.<id>` |
| `pool` | `r` | `depth` (1.4) | basin, water, coping, ladder, underwater light; walkers cannot fall in |
| `water` | `r` | | shallow pond with a stone edge |
| `court` | `r` | `material` | sports court with lines |
| `pergola` | `r` | `h` (2.8), `climber` (true) | timber pergola (no beams into the house), flowering climber |
| `garden` | `r` | `flowers` (true) | planting bed with shrubs and flowers |
| `trees` | `r` | `spacing` (4), `species`, `scale: [min, max]` | trees scattered in the rect (keeps clear of the house, paths, pool) |
| `tree` | `c: [x, y, scale]` | `species` | one tree. species: `'shade'`, `'fruit'`, `'olive'`, `'cypress'` |
| `wall` | `from: [x, y]`, `to: [x, y]` | `h` (1.8), `t` (0.2), `material` | garden wall (straight along x or y) |
| `fence` | `from`, `to` | `h` (1.6) | post-and-net fence |
| `hedge` | `from`, `to` | `h` (1.4), `t` (0.7) | clipped hedge |
| `gate` | `from`, `to` (on the plot edge) | `type: 'sliding' \| 'swing'`, `auto` (sliding: true), `h`, `slide: 'start' \| 'end'` | gate posts + a moving leaf. Automatic gates open when someone or a car comes near |
| `building` | `r` | `h` (2.8), `roofMaterial` | small outbuilding (box + hip roof) |

### levels

```js
levels: [
  { id: 'L1', name: { id: 'Lantai 1', en: 'Ground floor' }, short: 'L1', elev: 0.15, h: 3.4 },
  { id: 'L2', name: { id: 'Lantai 2', en: 'Upper floor' },  short: 'L2', elev: 3.55, h: 3.2 },
]
```
`elev` = finished floor above the garden; `h` = floor-to-floor height (clear ceiling = `h − 0.3`).
The next level's `elev` should be `elev + h` of the one below. Basements: `elev < 0` (e.g. `-3.2`);
the lowest non-basement level is the ground floor (its walls start at the garden, 0).

### rooms

```js
rooms: {
  L1: [
    { id: 'living', name: { id: 'Ruang keluarga', en: 'Living room' }, short: 'Living', use: 'living', r: [2, 10, 9, 15.5],
      note: { id: '…', en: '…' } },
  ],
}
```

| Field | Meaning |
|---|---|
| `id` | unique in the whole house, letters/digits/`_`/`-`, starts with a letter |
| `name`, `short` | full name (tooltips) and short label (plan, dollhouse) |
| `use` | `living`, `family`, `dining`, `kitchen`, `bedroom`, `master`, `guest`, `bath`, `wc`, `laundry`, `study`, `foyer`, `hall`, `stair`, `storage`, `closet`, `garage`, `utility`, `media`, `gym`, `prayer`, `other` — drives the default floor, wall finish and the spec counts |
| `zone` | colour group in the plan (default from `use`): `public`, `private`, `master`, `work`, `hobby`, `service`, `circulation`, `utility`, `garage`, `outdoor`, `water`, `energy` |
| `r` | rectangle on the 0.5 m grid. Rooms of one level must not overlap; an L-shaped space = two rooms + an `open` pair |
| `note` | free text (tooltip) |
| `noLabel` | hide the label (second half of an L-shaped room) |

### open

Pairs of rooms on the same level with **no wall** between them (open plan). They must touch.
```js
open: { L1: [['living', 'dining'], ['kitchen', 'dining'], ['stair', 'living']] }
```

### openings (doors and windows)

```js
openings: {
  L1: [
    { o: 'h', x: 5.4, y: 6, w: 1.2, t: 'double', side: 1 },            // front door in the south wall (y = 6)
    { o: 'v', x: 7.5, y: 8.0, w: 0.8, t: 'swing', side: 1, hinge: 'e' }, // door in a wall along y at x = 7.5
    { o: 'v', x: 2, y: 10.5, w: 1.8, t: 'window' },
  ],
}
```

| Field | Meaning |
|---|---|
| `o` | `'h'`: in a wall running along x (at `y`), the opening spans `x … x + w`. `'v'`: in a wall along y (at `x`), spans `y … y + w` |
| `x`, `y` | must lie exactly on a room edge (a wall line) |
| `w` | width (m) |
| `t` | type (below) |
| `side` | `+1`: the leaf swings towards +y (`h`) / +x (`v`); `-1` the other way. Sliding/folding: the side the moving panel runs on |
| `hinge` | `'s'` hinge at the start end (small x / y), `'e'` at the far end (swing doors) |

| t | kind | heights |
|---|---|---|
| `swing` | hinged door | head 2.2 m |
| `double` | two hinged leaves | 2.4 m |
| `sliding` | glass sliding door: half fixed, half slides | 2.7 m |
| `folding` | glass bi-fold door | 2.7 m |
| `garage` | rolling shutter | 2.6 m |
| `opening` | doorway without a leaf | 2.6 m |
| `window` | window | sill 0.9 m, head 2.3 m |
| `glass` | fixed floor-to-head glass | 0.05 – 2.7 m |
| `high` | high / clerestory window (privacy) | 2.4 – 3.2 m |

Openings on the same wall must not overlap. Keep doors ≥ 0.3 m from wall corners. Every room needs
at least one door / opening / open-plan link (`check` walks into every room).

### fixtures (optional)

Simple built-ins drawn with the shell (prefer real furniture in `interior.js`):
`{ t: 'counter' | 'island' | 'wc' | 'sink' | 'shower' | 'tub' | 'bench', r }`,
`{ t: 'partition', from, to, h }` (half-height divider), `{ t: 'solid', r, h, material }` (column / duct),
`{ t: 'stall', r }` (parking lines), `{ t: 'vine', from, to }`, `{ t: 'plant', c: [x, y, radius] }`.
A room whose interior entry has `replaceFixtures: true` skips its counter / island / wc / sink / tub / bench boxes.

### stairs

```js
stairs: [
  { id: 'main', type: 'U', r: [2.15, 6.15, 4.425, 9.95], up: 's', first: 'right', from: 'L1', to: 'L2' },
  { id: 'back', type: 'straight', r: [2.15, 4.0, 3.35, 9.7], up: 'n', from: 'G', to: 'U' },
]
```

| Field | Meaning |
|---|---|
| `type` | `'straight'`: one flight over the whole rect. `'U'`: first flight climbs on one half to a landing at the far end, the second climbs back on the other half |
| `r` | the stair's footprint. Usually inside the inner wall faces of a room (inset 0.15 / 0.075 from the room edges) |
| `up` | direction the (first) flight climbs |
| `first` | U only: `'right'` / `'left'` half for the first flight, seen looking up it |
| `landing` | U only: landing depth (default = flight width, ≥ 1 m) |
| `from`, `to` | lower and upper level ids (one stair per pair of levels; stack them for more floors) |

Rules (checked by `validate`): risers ≈ 17 cm, going ≥ 25 cm → a straight stair for 3.4 m needs about
5 m length, a U-stair about 3.8 m × 2.3 m. The foot (0.5 m before the first step) must be inside a
room of `from`, the arrival inside a room of `to`. The rect is cut out of the upper floor; its open
edges get a balustrade automatically (not where a wall closes them, not where the stair arrives).

### lift (optional)

```js
lift: { r: [8.1, 6.15, 9.6, 7.8], door: 'w', stops: ['L1', 'L2'] }
```
Shaft rect (≥ 1.3 × 1.5 m), the side the door is on, the levels it stops at (default all). Put it
inside or beside a hall; keep 1.5 m free in front of the door. The engine builds the shaft, the car,
landing doors, call buttons and the floor panel (keys 1…n inside the car).

### outdoor (balconies, roof terraces)

```js
outdoor: { L2: [{ id: 'balcony', kind: 'balcony', name: 'Balkon', r: [2, 15.5, 6, 17], rail: 'auto', material: 'teak' }] }
```
A walkable deck at that level's floor height; glass railing on the edges not against a room
(`rail: 'auto'`, or a string of sides like `'nse'`). `kind: 'roofTerrace'` uses a gravel deck finish.

### roofs

```js
roofs: [
  { id: 'main',   type: 'hip',   r: [2, 6, 13, 15.5], on: 'L2', pitch: 0.45, over: 0.9, pv: true },
  { id: 'garage', type: 'gable', r: [13, 6, 18, 12], on: 'L1', pitch: 0.5, over: 0.5, ridge: 'y' },
  { id: 'back',   type: 'shed',  r: [6, 10.5, 11, 12], on: 'L1', pitch: 0.15, over: 0.4, down: 'n' },
  { id: 'canopy', type: 'flat',  r: [4, 4.6, 8, 6], base: 3.0, over: { w: 0.1, s: 0.1, e: 0.1, n: 0 }, parapet: 0 },
]
```

| Field | Meaning |
|---|---|
| `type` | `hip` (four slopes), `gable` (two slopes + gable walls), `shed` (one slope + infill walls), `flat` (slab, optional parapet) |
| `r` | the area under the roof **without** the overhang (normally the rooms it covers) |
| `on` | level whose wall tops carry the eaves (eave height = that level's `elev + h`) — or `base`: eave height in m |
| `pitch` | rise / run (0.45 ≈ 24°, 0.58 ≈ 30°) |
| `over` | overhang in m, or per side `{ w, s, e, n }` (0 where the roof meets a taller wall) |
| `ridge` | gable: `'x'` or `'y'` (default the longer side) |
| `down` | shed: the low side |
| `material` | overrides `style.roof` |
| `pv` | hip roofs: solar panels on the planes facing the equator, east and west |
| `parapet`, `thickness` | flat roofs (m) |

Every room needs something above it — the floor of the level above or a roof (validate warns).

## interior.js

```js
export default {
  version: '1.0',
  rooms: {
    living: {
      finish: { walls: 'paint', wallColor: '#e7e1d6', floor: 'wood', curtains: 'drapeCream', windowFrame: 'ironBlack' },
      items: [
        { type: 'sofa', x: 6.0, y: 13.35, rot: 270, w: 2.2, fabric: 'fabricSage', seats: 3 },
        { type: 'tv', x: 2.15, y: 13.5, rot: 90, z: 1.35 },          // wall item: x on the inner wall face
        { type: 'ceilingFan', x: 4.4, y: 13.35 },                    // ceiling item
      ],
    },
  },
  areas: {
    carport: { items: [{ type: 'sedan', x: 14.6, y: 5.0, rot: 0, color: '#2c3e50' }] },
  },
};
```

- `rooms.<roomId>`: every room should have an entry (at least a `finish`).
- `areas.<siteItemId>`: furniture outside the rooms, at garden level (carport, terrace, pergola, pool
  deck). An area may also name `level` and `elev`, and the id of a balcony places it on that level.
- **Item**: `type`, `x`, `y` (footprint centre; wall items: the point on the inner wall face;
  ceiling items: the point below), `rot` (front direction), `z` (wall items: centre height on the
  wall; table lamps: the height of the surface they stand on), plus size overrides `w`, `d`, `h`
  and type params (catalogue below).
- `enclosed: true` on a room: windowless — its lamps stay on by day.
- `replaceFixtures: true`: skip the room's simple fixture boxes (see fixtures).

**finish** (all optional; defaults depend on the room's `use`):

| Field | Values |
|---|---|
| `walls` | `paint`, `wainscot` (panel below a chair rail), `panel` (full-height), `wallpaper`, `tile`, `concrete`, `acoustic` |
| `wallColor` | `#rrggbb` (paint / upper wall) |
| `panelColor` | `#rrggbb` or a wood material (`walnut`, `oak`, `mahogany`, `teak`, `cherry`) |
| `trim` | `#rrggbb` (baseboard, crown, door casings) |
| `ceiling` | `flat`, `tray` (+ `cove: true` LED cove), `coffered`, `beams` |
| `crown`, `baseboard` | true / false |
| `floor` | a floor material name |
| `curtains` | `drapeCream`, `drapeBurgundy`, … or omit |
| `windowFrame` | `ironBlack`, `trimWhite`, `walnut` |

**Layout rules** (checked by `npm run check-interior`): items inside their room's inner wall faces;
solid items do not overlap each other, fixtures, stairs or the lift; nothing solid in a door's
clear zone (1 m each side of the door + the swing); a ≥ 0.8 m walking path from every door to the
room's main area; nothing taller than 1.2 m in front of a window (2.3 m for high windows); wall
items on a real wall, not over an opening; ceiling items leave ≥ 2.1 m headroom.

## Cost estimate

The cost page (`studio/cost.html`) computes quantities from the plan in the browser
(`engine/cost/quantities.js`) and prices them with a **rate table per region**
(`engine/cost/rates/<region>.js`). `npm run quantities` writes the same numbers to
`projects/<name>/quantities.json` for reading.

**Rate table format** (`export default`):

```js
export default {
  id: 'jawa-barat-2026', name: { id: 'Jawa Barat 2026', en: 'West Java 2026' }, currency: 'IDR', locale: 'id-ID',
  note: { id: '…', en: '…' },
  QUALITY: { standard: { label: { id, en }, m: 1.0 }, premium: { …, m: 1.4 }, luxury: { …, m: 2.0 } },
  DEFAULTS: { quality: 'standard', region: 1.0, fee: 5, cont: 10, ppn: 11, range: 15 },  // %, ± %
  FEES: [{ n: { id, en }, share: 0.6 }, …],             // split of the design fee
  PERMITS: [{ n: { id, en }, r: 9000000, perM2: false, reg: true }, …],
  CATEGORIES: [
    { id: 'structure', name: { id, en }, items: [
      { id: 'slab', n: { id, en }, u: 'm²', q: (Q, A) => Q.upperArea, r: 1150000, qs: 0.3, lv: 'upper' },
    ] },
  ],
};
```
- `q(Q, A)`: quantity from the quantities object `Q` (fields: `gfa`, `footprint`, `upperArea`,
  `levels{…}`, `walls{extArea, intArea, …}`, `openings{type: {n, area}}`, `roofs{plan, sloped, byType,
  byMaterial}`, `finishes{floor{material: m²}, wallTile, wallPaint, ceiling}`, `wet{…}`, `kitchen{runM}`,
  `stairs`, `lift`, `balconies`, `site{paving, lawn, pool{area, volume}, perimeter{wall, fence}, gates, trees, …}`,
  `pv{kwp}`, `furniture{type: n}`, `cars`).
- `r`: unit rate at quality 1.0; `qs`: quality sensitivity (rate × (1 + qs × (m − 1)));
  `lv`: cost allocation `'gfa' | 'ground' | 'upper' | 'site' | <levelId> | (Q) => weights`;
  `reg: false`: not scaled by the regional price index.

**Add a region**: copy `engine/cost/rates/jawa-barat-2026.js` to `engine/cost/rates/<new-id>.js`,
change `id`, `name`, `note` and the rates, register it in `engine/cost/rates/index.js` (`RATES`), and
set `"cost": { "region": "<new-id>" }` in project.json. Unknown regions fall back to
`jawa-barat-2026` with a warning on the page. All figures are **estimates**, not quotations.
